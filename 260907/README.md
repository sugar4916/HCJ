# VISIT BUSAN - 日本人向け釜山旅行ガイド

일본인 관광객을 타깃으로 기획·제작된 반응형 부산 공식 관광 안내 웹사이트입니다.
웹 표준, 웹 접근성, 유지보수성을 극대화한 시맨틱 구조와 최신 CSS/JS 인터랙션이 적용되어 있습니다.

---

## 1. 프로젝트 개요

- **프로젝트명**: VISIT BUSAN (일본인을 위한 부산 여행 가이드)
- **타깃 사용자**: 2030 자유여행객 및 가족 단위 일본인 관광객
- **언어 환경**: 일본어 (Noto Sans JP 웹폰트 기반)
- **제작자 역할**: 10년차 전문 웹 퍼블리셔 겸 튜터

---

## 2. 디렉토리 구조

요청 명세에 따른 표준 웹 에셋 구조를 엄격히 준수합니다.

```
antigvt/
  ├── assets/
  │   ├── css/
  │   │   └── style.css       # 리셋, 폰트, CSS 변수 및 커스텀 컴포넌트 스타일
  │   ├── js/
  │   │   └── main.js         # 스크롤 제어, 필터, 아코디언, 클립보드 인터랙션
  │   └── img/
  │       └── .gitkeep        # 로컬 이미지 리소스 디렉토리
  ├── index.html              # HTML5 시맨틱 웹 표준 마크업
  ├── README.md               # 프로젝트 기술 가이드 및 퍼블리싱 학습 문서
  └── GEMINI.md               # 프로젝트 작업 가이드라인
```

---

## 3. 기술 스택 및 라이브러리

- **Markup**: HTML5 (시맨틱 태그: `header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS Framework**: Tailwind CSS (CDN)
- **Custom Style**: CSS3 (CSS Custom Properties / 변수 시스템, 반응형 미디어 쿼리)
- **JavaScript**: Vanilla JS ES6+ & jQuery 3.7.1
- **Icons**: Font Awesome 6.5.1 (SVG/Font 기반, 이모지 배제 원칙 준수)
- **Typography**: Google Fonts (Noto Sans JP, Outfit)

---

## 4. 10년차 퍼블리셔의 핵심 설계 및 튜터 가이드

### (1) 웹 접근성(A11y) 및 시맨틱 구조화
- **스킵 네비게이션**: 키보드 및 스크린 리더 사용자를 위해 본문으로 즉시 건너뛸 수 있는 `.sr-only` 스킵 링크를 최상단에 배치했습니다.
- **포커스 링 보존**: `:focus-visible` 가상 클래스를 통해 키보드 내비게이션 시 시각적 인디케이터를 명확히 제공합니다.
- **WAI-ARIA 및 시맨틱 태그**: 단순 `div` 남발을 지양하고 구획 태그와 `aria-label`을 적용하여 검색엔진 최적화(SEO)와 보조기기 판독성을 높였습니다.

### (2) 다국어(일본어) 타이포그래피 최적화
- 일본어 특유의 줄바꿈과 가독성을 고려하여 `Noto Sans JP`를 1순위로 지정하고, 영문 서체는 기하학적 산세리프인 `Outfit`을 조합했습니다.
- 행간(`line-height: 1.7`)과 자간(`letter-spacing: 0.02em`)을 정밀 조정하여 장시간 열람 시에도 피로도가 적도록 세팅했습니다.

### (3) CSS 아키텍처: Tailwind와 커스텀 CSS의 역할 분담
- 레이아웃 및 1회성 간격/정렬은 Tailwind의 유틸리티 클래스로 신속히 처리합니다.
- 복잡한 상태 변화(스크롤 헤더 블러, 카드 리프트 호버, 아코디언 접힘/펼침 트랜지션)는 `assets/css/style.css` 내 CSS 변수(`--color-primary`, `--transition-normal` 등)와 결합하여 코드의 일관성과 재사용성을 확보했습니다.

### (4) 실무형 jQuery 인터랙션 모듈화
- **스크롤 연동 헤더**: `$(window).on('scroll')`을 통해 스크롤 깊이에 따라 반투명 글래스모피즘 효과가 적용됩니다.
- **동적 카테고리 필터**: `data-category` 어트리뷰트와 jQuery 셀렉터를 활용하여 렌더링 비용을 최소화하면서 부드러운 페이드 전환을 구현했습니다.
- **원클릭 클립보드 복사**: 모바일 여행객의 편의를 위해 필수 한국어 문장을 탭하면 즉시 복사되고 피드백 애니메이션이 나타나도록 설계했습니다.

## 5. 실행 및 브라우저 호환성

별도의 빌드 도구 없이 브라우저에서 `index.html`을 직접 실행하거나 라이브 서버 환경에서 구동 가능합니다.

- **지원 브라우저**: Chrome, Edge, Safari, Firefox 최신 버전
- **반응형 브레이크포인트**:
  - Mobile: < 640px
  - Tablet: 640px ~ 1023px
  - Desktop: 1024px 이상
