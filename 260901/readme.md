# 📋 교육 프로그램 만족도 조사 웹앱

Google Apps Script와 Tailwind CSS를 활용하여 제작한 교육 프로그램 만족도 조사 웹 애플리케이션입니다.

## 📁 파일 구조
- `Code.gs`: Google Apps Script 백엔드 로직 (데이터 검증 및 Google Sheets 자동 저장)
- `index.html`: Tailwind CSS 적용 만족도 조사 UI 화면
- `README.md`: 프로젝트 설명서

## 📌 주요 기능
1. **설문 응답 제출**: 이름, 만족도, 유익했던 내용, 기타 의견 입력
2. **필수 항목 검증**: 이름, 만족도, 유익했던 내용 필수 체크
3. **Google Sheets 연동**: 제출 일시 및 설문 데이터 시트 자동 추가
