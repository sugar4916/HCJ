# 🔮 Element Fortune (오늘의 원소 운세)

사용자의 성함, 생년월일, 성별과 함께 **5가지 동양/자연 원소 기운(불🔥, 물💧, 나무🌿, 흙⛰️, 바람🌬️)**을 선택하여 오늘의 맞춤형 운세, 별점, 행운의 컬러 및 행운의 숫자를 확인하는 웹 기반 운세 서비스입니다.

---

## ✨ 주요 기능 (Key Features)

- **5가지 원소(Element) 기반 운세 테마**:
  - **불 (Fire 🔥)**: 열정, 리더십, 결단력 중심의 운세
  - **물 (Water 💧)**: 지혜, 포용력, 순조로운 대인관계 중심의 운세
  - **나무 (Wood 🌿)**: 성장, 성찰, 새로운 시작 중심의 운세
  - **흙 (Earth ⛰️)**: 안정, 결실, 내실 다지기 중심의 운세
  - **바람 (Wind 🌬️)**: 소통, 인연, 자유로운 흐름 중심의 운세
- **사용자 정보 맞춤 설정**:
  - 이름, 생년월일, 성별 선택 입력 파라미터
- **운세 결과 및 럭키 아이템 대시보드**:
  - 원소별 테마 색상 및 아이콘 반영 카드 노출
  - 종합 운세 제목, 상세 가이드 텍스트 및 별점(★) 표시
  - **행운의 컬러** & **행운의 숫자** 맞춤 추천
- **인터랙티브 UI & 감성적 디자인**:
  - 마우스 커서 위치를 실시간 추적하는 파스텔 그라데이션 백드롭
  - 글래스모피즘(Glassmorphism) 및 카드 레이아웃
  - Pretendard 웹 폰트 및 FontAwesome 6 아이콘 탑재
- **원클릭 재도전**:
  - '다시 점치기' 버튼을 제공하여 손쉽게 재조회 가능
